1. Odprite terminal v glavni mapi projekta.

2. Namestite vse osnovne odvisnosti:
   npm install

3. Aplikacija uporablja Bebas Neue pisavo. Prepričajte, da so naloženi naslednji dodatki, tako da zaženete ta ukaz:
   npx expo install expo-font @expo-google-fonts/bebas-neue

4. Zaženite strežnik:
   npx expo start
